# 📱 MobileMart - Online Shopping Website

## 📌 Project Overview
MobileMart is a responsive e-commerce website developed using HTML, CSS and JavaScript. Users can search mobiles, add products to cart, manage quantity, add items to wishlist, buy products and place orders.

## 🚀 Features
- Responsive Design
- Search Mobile
- Add to Cart
- Wishlist
- Buy Now
- Quantity Increase & Decrease
- Checkout
- Order Success Page
- Contact Form
- Mobile Friendly Layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
